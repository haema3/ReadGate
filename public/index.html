해커톤 참가 안내 · v1

심사 당일을 위한 짧은 안내

참가 확인은 안내를 끝까지 읽는 것에서 시작합니다. 데모 시간, 제출 형식, 팀 정보의 마감 시각을 한 장의 체크리스트로 정리하면 마지막 순간의 실수를 줄일 수 있습니다. 발표 전에는 심사자가 직접 눌러 볼 한 가지 흐름을 골라 두세요.

좋은 데모는 기능을 많이 나열하지 않습니다. ReadGate에서는 글을 빠르게 넘긴 뒤 다음 단계 버튼을 누르면, 확인이 필요한 문단만 짧은 질문으로 되돌려 봅니다. 오답일 때는 다음 단계가 잠긴 채 관련 문단으로 돌아갈 수 있고, 정답을 맞히면 흐름이 이어집니다.

플랫폼 사용은 화면의 로고보다 실행 기록으로 설명합니다. Daytona에서 같은 SDK 예제를 테스트하고, Nosana GPU 작업에서 생성한 문항을 검수해 사용합니다. 실행 결과와 생성 출처는 남기되, API 키와 계정 정보는 어디에도 표시하지 않습니다.

행동 신호는 읽기 여부의 추정치이며 이해도를 단정하지 않습니다.
